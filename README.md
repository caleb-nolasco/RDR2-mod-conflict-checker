# RDR2 Mod Checker

Detects file conflicts in between RDR2 Mods

## Features
- Recursive File Searching
- User input to flag down which conflicts (in case they want to keep any)

## 💻 Getting Started

## Prerequisites
Using native libraries
Written in Java

## 🛠️ Usage
When running multiple mods, launch this executable in your game directory to detect conflicts.
